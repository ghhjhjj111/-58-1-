# 同城信息小程序便民信息小程序58同城商家入驻信息发布招聘小程序

源码地址：ym7k.com/19289/

今天给大家分享一款功能齐全的同城分类信息小程序源码，对标 58 同城本地便民门户模式，适配货车、工程车行业同城信息服务，自带后台管理系统，支持商家入驻、信息发布、招聘求职、车找活、活找车、二手车辆交易等全套业务，适合搭建地方同城便民平台、工程车辆信息门户。

整套程序由 PC 管理后台 + 微信小程序前端组成，后台功能完善，可视化配置简单，站长可以独立管控整个平台内容与盈利项目。

### 后台管理功能

后台包含系统管理、会员管理、商家管理、社区管理、收费管理、订单管理、内容管理、权限管理、微信管理九大模块。
系统设置面板支持自定义网站标题、上传前台与后台 Logo、配置商家入驻保证金、附近信息推送距离，同时拥有提现配置、短信配置，方便对接短信通知、资金提现流程，所有基础参数无需改代码，后台直接保存生效。
支持会员分级管理、商家入驻审核、帖子内容审核、置顶广告管理；可自主设置置顶收费、入驻保证金、会员套餐，打造平台变现体系。

### 小程序前端核心功能

首页采用本地化城市定位，顶部搜索框可以快速检索信息，轮播 banner 用于招商入驻广告展示，分区模块清晰划分：车辆买卖、找活找车、招聘求职。
功能入口覆盖热点资讯、新车销售、保险购买、过户审车、维修保养、配件销售、挂靠公司，贴合工程运输行业需求，也可以改成通用便民版本。
附近页面做分类标签：全部、卖车、买车、招聘、求职、活找车，自带定位距离展示，支持一键拨打电话，帖子支持点赞、浏览统计、置顶标识，本地信息一键筛选。
个人中心模块丰富：我的帖子、我的资讯、评论、收藏、钱包、拨打记录；同时配备客服入口、新手教程、商家入驻、代理加盟通道，给商家和代理商留出拓展入口。
底部导航：首页、附近、发布、商家、我的，用户点击中间加号就能自主发布信息，发布内容进入后台审核，过滤违规信息。

✅ 多业务板块合一：二手车辆交易、招聘求职、活源运力、本地服务
✅ 商家入驻机制，支持保证金设置，保障平台可信度
✅ 变现渠道多样：帖子置顶费、会员充值、商家入驻费、广告招商、代理加盟
✅ 独立钱包、提现、短信通知、订单记录整套资金链路
✅ 后台可视化配置，Logo、站点名称、距离、保证金均可后台修改
✅ 可二次开发，既能做工程车垂直平台，也能改成通用同城便民小程序

### 适用场景

地方同城便民信息平台、工程搅拌车 / 货车运力信息平台、本地招工求职平台、二手车交易信息平台、乡镇同城分类门户。
